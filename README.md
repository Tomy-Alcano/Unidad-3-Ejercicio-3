# Unidad-3-Ejercicio-3
Programacion 3 Unidad 3 Ejercicio 3
Ejercicio 3 — Mi primera JTable
Este ejercicio introduce el componente JTable y su uso con DefaultTableModel. El objetivo es que construyas una tabla con datos iniciales y practiques las operaciones básicas sobre el modelo.

Creá una ventana que muestre una tabla de productos con las siguientes columnas: ID, Nombre, Categoría, Precio.

La tabla debe:

Estar envuelta en un JScrollPane
Iniciar con al menos 5 filas de datos cargadas directamente en el código
Tener las celdas no editables por el usuario
Mostrar una selección de una fila a la vez
Debajo de la tabla, agregá:

Un botón con el texto "Agregar producto de prueba" que agregue una fila nueva con datos fijos a la tabla cada vez que se presione
Un botón con el texto "Eliminar fila seleccionada" que elimine la fila actualmente seleccionada. Si no hay ninguna fila seleccionada, debe mostrar un mensaje de advertencia usando JOptionPane
Una etiqueta que muestre en todo momento la cantidad de filas en la tabla
💡 Tip: para obtener la cantidad de filas del modelo usá modelo.getRowCount(). Recordá actualizar la etiqueta del contador cada vez que se agregue o elimine una fila.
